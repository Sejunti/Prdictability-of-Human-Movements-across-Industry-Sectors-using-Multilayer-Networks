# Prdictability-of-Human-Movements-across-Industry-Sectors-using-Multilayer-Networks
Jupyter notebooks for analyzing the SafeGraph dataset on time-varying, multilayer mobility networks to predict human movement pattern within Harris County, 
Texas (From Monday, January 8, 2018 to Monday, December 30, 2019). 

**Overview:**
1. Develop models to predict nodes’ weekly and time-averaged in- and out-degrees. 
2. Train predictive models based on two types of input data: infrastructure information
and socioeconomic information.
3. Compare ten predictive models: limear and nonlinear machine learning models.
